# スキンケア・ノート（個人用）

汎用版「スキンケア・ノート」（Ginji001/skincare-note）と同じ仕様の個人用コピーです。

- コードは汎用版と同じ。データの保存先だけ個人用に分けています（同じブラウザでも汎用版とデータが混ざりません）
- 個人データはリポジトリに含めません。データは端末内（localStorage）だけに保存します
- 以前の個人用アプリのデータが端末に残っていれば、初回に自動で新しい形式へ変換します
- 以前の形式のデータファイル（skincare-data.json）は「設定」→「バックアップから戻す」で読み込めます

文字認識に Tesseract.js 7.0.0（Apache-2.0）を vendor/ocr に同梱しています。
